JAVA PROGRAMMING — 300-WORD WRITE-UP
=====================================
Project: Library Management System (Spring Boot + MySQL)

────────────────────────────────────────────────────────

I applied Java programming to build a full-stack Library Management System using Spring Boot 3 and MySQL. The project demonstrates core Java and enterprise development skills through a practical, real-world application.

On the backend, I used Java's object-oriented principles to design three JPA entities — Book, Member, and BorrowRecord — each mapped to MySQL tables via Hibernate annotations. I applied encapsulation by keeping all business logic in a dedicated Service layer, separating it cleanly from the Controller (REST API) and Repository (database access) layers, following the standard MVC + Repository pattern.

The BorrowService class showcases Java's key strengths: I used @Transactional to ensure borrow and return operations are atomic — if the book availability update fails, the entire transaction rolls back, preventing data inconsistency. Business rules are enforced programmatically: a member cannot borrow more than 5 books simultaneously, must have ACTIVE status, and cannot borrow the same book twice without returning it.

I used Spring Data JPA to write custom JPQL queries with @Query, eliminating boilerplate SQL while retaining database flexibility. Jakarta Bean Validation annotations (@NotBlank, @Email, @Min) handle input validation automatically, and a GlobalExceptionHandler class converts exceptions into structured JSON error responses — making the API robust and developer-friendly.

The REST controllers expose fully documented endpoints supporting search, filtering, and statistics. The project includes automatic sample data seeding on startup using Spring's CommandLineRunner, making it easy to demo.

The frontend, built with HTML5, CSS3, and vanilla JavaScript, communicates directly with the Spring Boot API, displaying real-time book availability, overdue alerts, and member borrow history.

This project reinforced my understanding of Java generics (in JPA repositories), interface-based programming, exception handling hierarchies, and building production-ready applications with the Spring ecosystem.
